# IPCE 交互测量与光谱积分软件

这个程序把连续的 i-t 扫描按波长驻留时间切分，先利用硅基标探的已知响应度和受光面积反算每个波长的单色光功率密度，再用样品的稳态光电流密度计算 IPCE。

## Windows C# 便携版

当前面向日常使用的 Windows 版本位于
`csharp/dist/IPCEApp_Windows_x64.zip`。它是自包含的 Windows x64
应用，不需要安装 MATLAB、MATLAB Runtime 或 .NET Runtime。请完整解压
ZIP 后运行根目录的 `IPCEApp.exe`。

C# 版保留 MATLAB 版的计算公式、单位和不外推原则，并提供以下工作流：

- 同一程序内置完整英文和简体中文界面。首次启动按 Windows 语言选择，
  非中文系统默认英文；窗口右上角可随时在 `English` 与 `中文` 之间切换，
  选择保存在 `%LOCALAPPDATA%\IPCEApp\settings.json`。切换只更新显示文字，
  不会清除导入数据、参数、计算结果、积分结果或改变导出数值。
- i-t 表头能识别受支持的时间单位 `s/sec/second/ms/min/h` 和电流单位
  `A/mA/uA/µA/μA/nA/pA` 时自动换算到内部规范单位 `s/A`；缺少单位时
  要求用户在选择器中明确指定，绝不会按数值大小猜测。
- 光谱导入会选择工作表及波长/辐照度列；外部 IPCE 支持
  TXT、CSV、XLS 和 XLSX。
- 硅与样品锚点表彼此独立，可添加、编辑、应用和删除；调度预览会在计算前
  显示数据覆盖范围，越界点以红色显示。样品时间对齐初始选择锚点模式，
  用户也可明确切换到固定 Delay 模式。
- 结果区包含 `i-t 轨迹`、`时间调度`、`功率密度`、`IPCE`、
  `光谱积分` 和 `结果摘要`。图形默认显示约 99% 的主体数据范围，避免
  漏光等少数大阶跃把主体曲线压扁；状态文字会报告视野外极端点数，
  “显示全部”可恢复完整范围，“复位视图”返回主体范围。
- 所有图形可把鼠标吸附到 12 像素内最近的真实数据点并显示坐标。i-t 图
  另外用粗橙线和中点标出各波长的实际平均电流窗口，悬停可查看波长、
  起止时间、平均电流和样本数；暗电流区间显示为灰色，积分区域显示为蓝色。
  这些区域仅用于屏幕显示，不改变计算、积分或导出数值。
- 图形支持滚轮缩放、拖动平移、坐标范围、线性/对数轴及 PNG 保存。
  刻度和图例字号为 20，坐标轴名称字号为 24，图标题字号为 26，并采用
  DPI 感知中文字体。
- 计算 IPCE 与外部 IPCE 始终保留为两套独立数据；外部 IPCE 不裁剪到
  `0–100%`。光谱积分只使用所选 IPCE 与光谱的共同波长覆盖范围。
- 输入或范围错误只显示可恢复警告，不会退出软件。修改面积、暗区间、调度、
  数据源或积分范围后，受影响的旧结果会标为“过期”，重新计算前不能作为
  下游输入或导出。
- XLSX、CSV 和 MAT 导出保留原有结果表名，并附加
  `MeasurementSettings`、`SiliconAnchors`、`SampleAnchors` 和
  `InputMetadata`，记录面积、暗区间、调度、积分范围、结果状态、原始单位、
  文件名及光谱工作表/列选择。

诊断日志位于 `%LOCALAPPDATA%\IPCEApp\Logs`。当前便携包仍须在一台
未安装 MATLAB 和 .NET Runtime 的 Windows 10/11 x64 电脑或虚拟机上完成

图形的主体范围、图层勾选和“显示全部”只影响屏幕显示，不会删除或裁剪
原始数据，也不会改变计算、积分或导出的任何数值。

## 完整测量流程

1. 导入硅标探响应度校准表。程序优先识别“波长 / wavelength / nm”和“响应度 / responsivity / A/W”等列名，也可回退到前两列有效数值。
2. 核对自动载入的硅标探 i-t 和标探锚点；其他批次可手动重新导入。
3. 在左侧“编辑标探参数 / 编辑样品参数”之间切换，分别设置两者的波长范围、步长、名义 Delay 和确认点后平均时长。两组参数完全独立。
4. 在“时间对齐”页填写硅标探的波长—时间锚点。锚点只表示在该时刻已经确认单色仪输出目标波长，不假设它是准确的切换开始时间。
5. 锚点可直接编辑；也可在 i-t 图中先用工具栏或滚轮放大，再使用“新增图上选点”。程序会吸附到最近的原始采样点，随后弹窗允许用户调整时间并输入波长。
6. “确认已有行”用于先在表格填写波长、再从图上更新该行时间。
7. 两个以上锚点采用分段线性插值；扫描范围两端采用最近两个锚点的斜率外推。只有一个锚点时，使用对应数据集的名义 Delay 推算。
8. 锚点模式从确认时间向后取稳态均值，并限制在该波长的时间单元内。固定 Delay 模式仍取每个驻留窗口末段。
9. 暗电流扣除默认启用。预置标探暗区间为 `0.1–10 s`、样品暗区间为 `50–60 s`。可在“暗电流”页直接修改，或在对应 i-t 图上依次选择起点和终点。
10. 输入标探受光面积和样品有效受光面积。默认分别为 `0.36 cm²` 和 `1 cm²`；程序分别用它们把标探总功率换算成功率密度、把样品总光电流换算成光电流密度。
11. 单击“反算单色光功率密度”，检查功率密度—波长曲线。
12. 导入样品 i-t。样品时间对齐初始选择锚点模式，可在“样品锚点”页输入或确认锚点；用户也可明确切换到固定 Delay 模式。再单击“计算样品 IPCE”。若样品波长网格与标探不同，程序会把标探功率密度形状保持插值到样品波长；不允许范围外外推。
13. 如需光谱积分，在“光谱积分”页把“IPCE 数据源”设为“本软件计算结果”，选择光谱工作表、波长列和积分列，再设置积分范围。下方会同时显示最终积分值和累计电流密度—波长曲线。
14. 所有图形都带有缩放、平移和恢复工具栏；“图形设置”页还可以精确输入 X/Y 范围并选择线性或对数刻度。
15. 单击“导出结果”后勾选需要的表、统计列和文件格式，然后选择路径。程序在写入后检查文件大小并显示绝对路径。

## 外部 IPCE 后处理流程

这条流程用于处理其他平台已经测得、但没有提供积分电流密度的 IPCE 数据。它不要求导入标探响应度、标探 i-t、样品 i-t 或时间锚点。

1. 打开“光谱积分”页，单击“导入 IPCE”。
2. 选择 `.txt`、`.csv`、`.xls` 或 `.xlsx` 文件。前两列有效数值依次解释为波长 `nm` 和 IPCE `%`；允许表头。
3. 导入成功后，软件保留本软件计算的 IPCE，并自动把“IPCE 数据源”切换为“外部导入 IPCE”。用户可随时在两者之间切换。
4. 导入标准太阳能光谱，选择工作表、波长列与光谱辐照度列。辐照度必须是 `W m^-2 nm^-1`。
5. 设置积分范围并单击“计算积分 J”。积分范围必须落在所选 IPCE 与光谱的共同覆盖范围内，软件不会外推。
6. 查看积分汇总和累计积分电流密度—波长曲线。
7. 单击“导出结果”，可独立导出外部 IPCE、积分汇总和积分曲线。积分曲线包含谱电流密度及累计积分电流密度。

外部 IPCE 按波长排序，重复波长的 IPCE 取平均。有限的超 `100%` 数据不会被裁剪。

## i-t 表头与单位

i-t 文件的内部规范单位始终是时间 `s`、总电流 `A`。导入时软件会读取并保留原始列标题，自动识别：

- 时间：`s`、`sec`、`second`、`ms`、`min`、`h`
- 电流：`A`、`mA`、`uA`、`µA`、`μA`、`nA`、`pA`

识别后自动换算到 `s/A`，并在表格元数据和导出参数中保留原单位及换算因子。表头缺少单位或单位无法识别时，界面会要求用户明确选择时间和电流单位，不会根据数值大小猜测。时间对齐文件仍固定为第一列 `nm`、第二列 `s`。

时间锚点也可以从两列文件导入。锚点页中的“导入 TXT”支持 TXT、CSV 和 Excel；前两列依次为波长（nm）与确认时间（s），允许带表头。导入会替换当前对应的标探或样品锚点表。

样品时间对齐初始选择锚点模式。“固定 Delay”模式仍然保留，用户可在明确知道首波长时刻且切换严格等间隔时显式切换使用。默认名义 Delay 为 `8 s`，确认点后平均时长默认为其一半 `4 s`。锚点模式有两个以上锚点时不会把实际窗口强制设为 8 s。

本目录现有硅标探 i-t 的数据范围约为 `0.1–1400 s`。界面默认从时间对齐文件载入 11 个标探锚点：

| 波长 (nm) | 时间 (s) |
| ---: | ---: |
| 310 | 44 |
| 335 | 85 |
| 355 | 122 |
| 405 | 204 |
| 450 | 278 |
| 480 | 327 |
| 505 | 368 |
| 555 | 454 |
| 830 | 909 |
| 905 | 1035 |
| 1080 | 1322 |

锚点值可随数据批次自由修改。对 `300–1100 nm / 5 nm` 扫描，程序用这些锚点分段线性插值并在两端按最近斜率外推。

## 计算公式

硅标探在波长 \(\lambda\) 的响应度为 \(R_\mathrm{Si}(\lambda)\)，扣除暗电流后的光电流为 \(\Delta I_\mathrm{Si}\)：

\[
p_\mathrm{inc}(\lambda)=
\frac{|\Delta I_\mathrm{Si}(\lambda)|}
{R_\mathrm{Si}(\lambda)A_\mathrm{Si}}
\]

其中 \(p_\mathrm{inc}\) 的单位为 \(\mathrm{W\,cm^{-2}}\)。样品扣除暗电流后的光电流密度为
\(J_\mathrm{sample}=|\Delta I_\mathrm{sample}|/A_\mathrm{sample}\)：

\[
\mathrm{IPCE}(\%) =
100 \times \frac{1239.841984\ J_\mathrm{sample}}
{p_\mathrm{inc}(\lambda)\ \lambda_\mathrm{nm}}
\]

程序保留有符号的总光电流列，同时在结果中给出功率密度和样品光电流密度；反算和 IPCE 使用绝对值。统计误差列是各平均窗口标准误差传播得到的估计值，不包括标探证书的不确定度、波长误差、光斑不均匀性、光路漂移或样品面积误差。

对于以 \(E_\lambda\) 表示的光谱辐照度，要求单位为
\(\mathrm{W\,m^{-2}\,nm^{-1}}\)。积分电流密度为：

\[
J = q\int_{\lambda_1}^{\lambda_2}
E_\lambda(\lambda)\frac{\lambda}{hc}
\frac{\mathrm{IPCE}(\lambda)}{100}\,d\lambda
\]

程序以光谱波长点为积分网格，在用户指定边界补点；光谱使用线性插值，IPCE 使用形状保持 `pchip` 插值。结果单位为 \(\mathrm{mA\,cm^{-2}}\)。积分曲线还输出
\(J_\mathrm{cum}(\lambda)\)，表示从积分起点到当前波长的累计电流密度；曲线最后一个点等于最终积分值。

## 重要实验假设

- 标探和样品可以使用不同的波长范围、步长、Delay 和时间锚点；但样品波长范围必须落在标探已反算的功率密度范围内。
- 标探和样品测量需使用可比较的光路、光斑定义和局部辐照度。功率密度换算假设标探与样品位置的光谱辐照度均匀且一致。
- 如果光斑小于样品、存在遮罩，或两次测量光斑不同，应输入各次测量的实际有效受光面积，而不是样品几何总面积。
- 当前锚点只代表“已经确认输出该波长”。程序从确认点向后平均，避免错误地把肉眼确认时间当作切换开始。
- 标探和样品的暗电流区间彼此独立；启用暗电流扣除后，两者都必须位于各自 i-t 数据范围内且至少包含两个采样点。
- 如果每个波长内还包含明暗斩波或多个阶段，仍需要增加“亮段/暗段”配对算法。
- 锚点间采用线性时间映射；如果单色仪在某一小段发生突发性额外卡顿，最好在该段前后各补一个锚点。
- 标探响应度只在证书覆盖范围内插值，不做范围外外推。
- 样品 i-t 输入必须表示总电流，而不是已经面积归一化的电流密度。原始电流可使用受支持的表头单位；软件换算为 A 后再用样品受光面积得到 \(\mathrm{A\,cm^{-2}}\)。
- 光谱积分下拉菜单显示真实表头；所选积分列必须确实是光谱辐照度且单位为 `W m^-2 nm^-1`。当前 ASTM G173 工作簿 `Spectra` 表的 A/C 列分别是波长和 Global tilt 光谱。
