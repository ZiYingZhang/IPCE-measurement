IPCEApp Windows x64 便携版
==========================

系统要求
--------
- Windows 10 或 Windows 11，64 位。
- 不需要安装 MATLAB、MATLAB Runtime 或 .NET Runtime。
- 请完整解压 ZIP 到普通可写目录后运行，不要直接在压缩包内启动。

启动
----
双击 IPCEApp.exe。程序会自动加载内嵌的硅探测器校准数据、默认硅 i-t、
默认硅时间锚点和标准太阳光谱。

主要流程
--------
1. 核对硅 i-t、锚点、面积和暗电流范围，计算单色入射功率密度。
2. 导入样品 i-t；时间对齐初始选择锚点模式，也可由用户明确切换到固定
   Delay 模式，然后计算样品 IPCE。
3. 或者仅导入外部 IPCE，选择太阳光谱后直接计算积分电流密度。
4. 在结果区查看 i-t、调度、功率密度、IPCE、光谱和累计积分曲线。
5. 导出 XLSX、CSV 或 MATLAB Level-5 MAT 文件。

导入与单位
----------
- 受支持的 i-t 表头单位会自动换算到内部规范单位 s/A；缺少表头单位时必须
  在对话框中明确选择，绝不会按数值大小猜测。
- 支持时间单位 s、sec、second、ms、min、h。
- 支持电流单位 A、mA、uA、µA、μA、nA、pA。
- 时间锚点固定为第一列 nm、第二列 s。
- 外部 IPCE 支持 TXT、CSV、XLS、XLSX；第一列 nm，第二列 %。
- 光谱辐照度为 W m^-2 nm^-1；Excel 导入时需确认工作表和两列。
- 积分及累计电流密度单位为 mA cm^-2。

图形与交互
----------
- 结果标签：i-t 轨迹、时间调度、功率密度、IPCE、光谱积分、结果摘要。
- 默认视野显示约 99% 的主体数据，避免少量漏光大阶跃压扁曲线；红色状态
  文字报告视野外极端点数。“显示全部”查看完整数据，“复位视图”返回主体
  范围。
- 鼠标会吸附到 12 像素内最近的真实数据点并显示坐标；移出图形后提示清除。
- i-t 图用粗橙线标出每个波长的平均电流及真实平均窗口，悬停显示波长、
  窗口、平均电流和样本数；暗电流区间显示为灰色，积分区域显示为蓝色。
  这些区域只用于屏幕显示，不改变计算、积分或导出数值。
- 可分别隐藏原始轨迹、暗电流区间、锚点与平均窗口。
- 滚轮缩放、左键拖动平移、双击恢复主体数据范围。
- 每张单图可输入 X/Y 上下限，选择 X/Y 对数轴，并保存当前 PNG。
- 时间调度中超出 i-t 数据范围的点显示为红色。
- IPCE 图同时显示计算结果和外部数据，并标明当前积分来源。
- 刻度和图例字号为 20，坐标轴名称字号为 24，图标题字号为 26，并随
  Windows 100%、125%、150% 缩放。
- 视野和图层设置只影响显示，不改变计算、积分或导出数值。

错误恢复与结果状态
------------------
- 文件、输入和范围错误会显示警告，窗口保持可用，不会因可恢复错误退出。
- 修改面积、暗区间、调度、上游数据或积分范围后，相关旧结果会标为过期。
- 过期结果不能继续用于下游计算或导出，需修正输入并重新计算。
- 意外错误的诊断日志位于：
  %LOCALAPPDATA%\IPCEApp\Logs

导出说明
--------
结果表名保持兼容，并附带：
- MeasurementSettings：面积、暗区间、调度、积分范围和结果状态。
- SiliconAnchors / SampleAnchors：当前有效锚点（存在时）。
- InputMetadata：输入文件名、表头、原单位、规范单位及光谱工作表/列选择。

注意事项
--------
- IPCE 与光谱只在共同波长覆盖范围内积分，不进行外推。
- 外部 IPCE 不会被截断到 0–100%。
- 计算 IPCE 与外部 IPCE 始终保持为两套独立结果。
- 使用新便携包前请保留旧包；正式发布仍需在无 MATLAB、无 .NET Runtime
  的干净 Windows 10/11 x64 环境完成一次完整验收。
