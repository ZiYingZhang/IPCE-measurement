# IPCE Measurement 中文教程

本项目用于完成光电化学测试中的完整计算链：由硅探测器校准和硅片 i-t 曲线得到单色入射功率密度，再由样品 i-t 曲线计算 IPCE，最后将 IPCE 与太阳光谱积分，得到积分电流密度及其随波长的累积曲线。

## 1. 选择程序

### C# WPF 版（Windows 推荐）

从 [GitHub Release 下载 IPCEApp_Windows_x64.zip](https://github.com/ZiYingZhang/IPCE-measurement/releases/download/v1.0.0/IPCEApp_Windows_x64.zip)，解压后运行 `IPCEApp.exe`。该压缩包是 self-contained 版本，不需要 MATLAB 或单独安装 .NET Runtime。

### MATLAB 版

MATLAB 源代码位于 `matlab/`。可从 [GitHub Release 下载 MATLAB 便携版](https://github.com/ZiYingZhang/IPCE-measurement/releases/download/v1.0.0/IPCEApp_R2023b_Windows_x64.zip)。该版本需要 64 位 MATLAB Runtime R2023b。MATLAB 版是数值参考实现，适合二次开发和核对计算结果。

## 2. 数据目录

仓库中已经准备好两类数据：

```text
data/defaults/   默认导入数据
data/examples/   可完成完整计算的示例数据
```


`data/defaults/` 中的默认文件由 MATLAB 和 C# 共用，程序启动时会尝试自动加载。`data/examples/` 中的文件用于演示完整流程；文件名会随版本调整，实际使用时以目录中的文件为准。示例数据不是程序运行的必需条件，用户可以随时替换为自己的数据。生成的 `dist/` 文件夹不会提交到源代码历史，编译程序统一放在 GitHub Release 附件中。

## 3. 完整计算流程

### 3.1 导入硅探测器校准数据

1. 在“硅校准”区域选择校准表格文件并导入。
2. 导入硅探测器的 i-t 文件。
3. 导入硅时间锚点文件；锚点的波长单位为 `nm`，时间单位为 `s`。
4. 确认暗电流扣除选项。默认暗区为 `0.1–10 s`。
5. 设置测量起始波长、终止波长和步长，以及探测器有效面积。

程序会把 i-t 数据转换为统一的内部单位：`Time_s` 和 `Current_A`。如果源文件缺少时间或电流单位，程序不会根据数值大小猜测，而会要求用户确认。

### 3.2 计算单色入射功率密度

点击“计算功率密度”。程序根据校准关系、硅响应度和硅 i-t 曲线，生成波长—入射功率密度数据，并在图中显示光谱区间和暗区区间。

图中常用单位为：

- 光谱辐照度：`W m^-2 nm^-1`
- 面功率密度：`µW cm^-2`

图形内部标题、坐标轴、刻度和图例采用英文科学标注，以保证不同 Windows 字体环境下的单位和上下标稳定显示；程序窗口和操作控件仍可切换中文/English。

### 3.3 导入样品数据并计算 IPCE

1. 导入样品 i-t 文件。
2. 导入样品时间锚点文件，或切换到固定延迟模式并输入固定延迟时间。
3. 设置样品暗区、扫描波长范围、步长、平均时长和有效面积。
4. 点击“计算 IPCE”。

样品暗区默认值为 `50–60 s`。样品电流先进行时间窗口提取和暗电流处理，再与入射功率密度结合得到 IPCE。计算结果和外部导入的 IPCE 数据在程序中保持为两套独立数据，不会互相覆盖。

### 3.4 光谱积分

1. 导入太阳光谱文件。
2. 选择要积分的 IPCE 来源：本程序计算的 IPCE，或外部两列 IPCE 文件。
3. 确认波长列、光谱辐照度列和 IPCE 列。
4. 设置积分区间。程序只在 IPCE 与太阳光谱的共同波长范围内插值和积分，不对区间外数据外推。
5. 点击“光谱积分”并查看积分值与累积曲线。

积分和累积曲线的单位为 `mA cm^-2`。积分区间用浅色填充显示，边界线为灰色虚线；这些显示设置只影响图形，不改变数值和导出结果。

### 3.5 导出结果

程序支持导出测量结果、外部 IPCE、积分电流密度以及“累积电流密度—波长”数据。建议在导出前保存当前图像，并保留输入文件、参数和导出的表格，便于复现实验记录。

## 4. 外部 IPCE 的独立处理

外部 IPCE 后处理不依赖硅校准、硅 i-t、样品 i-t 或时间锚点。只要准备一个至少包含两列数值的文件即可：

1. 第一列：波长 `nm`。
2. 第二列：IPCE `%`。

导入后可直接选择太阳光谱并进行积分。程序不会把有限的外部 IPCE 强行截断到 `0–100%`，以保留原始数据。

## 5. 文件格式和单位规则

- i-t 内部列名：`Time_s`、`Current_A`。
- 支持的时间单位：`s`、`sec`、`second`、`ms`、`min`、`h`。
- 支持的电流单位：`A`、`mA`、`uA`、`µA`、`μA`、`nA`、`pA`。
- 时间锚点文件：波长 `nm`，确认时间 `s`。
- 外部 IPCE：第一列 `nm`，第二列 `%`。
- 太阳光谱：`W m^-2 nm^-1`。
- 积分与累积电流密度：`mA cm^-2`。

程序不会从数字量级推断缺失单位。若表头单位与实际数据不一致，应先修正源文件或在导入时明确选择正确单位。

## 6. 常见问题

**默认文件没有自动出现？**  确认程序从仓库目录运行，且 `data/defaults/` 与程序包中的相对位置保持不变。也可以使用“浏览”按钮手动导入。

**示例数据能否完成全流程？**  可以。按 `data/examples/` 中的文件分别完成硅校准、硅 i-t、样品 i-t、时间锚点和光谱积分即可；如文件名有变化，以目录实际文件和表头为准。

**为什么积分范围被缩短？**  为避免外推，程序自动使用 IPCE 与光谱的共同波长覆盖范围。

**中文界面中的图标题为什么是英文？**  这是有意设计：图形内部文字统一使用 Arial 英文标注，避免中文字体缺字导致单位、上标或标题乱码；窗口控件、按钮和说明文字仍随语言选择显示中文或 English。
