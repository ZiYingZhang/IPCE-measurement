# IPCE Windows C# 迁移设计

日期：2026-07-27

## 1. 背景与目标

现有 IPCE 程序由 MATLAB 程序化 UI 实现，功能已经通过实际使用验证。
MATLAB Compiler 发布物仍要求目标电脑安装约 8 GB 的 MATLAB Runtime，
不适合轻量分发。

本次迁移把完整应用重写为仅面向 Windows 的 C# 桌面程序。目标是：

- 不依赖 MATLAB、MATLAB Runtime 或预先安装的 .NET Runtime。
- 以便携 ZIP 交付，解压后直接运行，不要求管理员权限。
- ZIP 体积小于 200 MB。
- 保持现有计算、导入、交互绘图、后处理和导出行为。
- 允许优化界面布局与外观，不要求逐像素复刻 MATLAB UI。
- 以现有 MATLAB 程序和自测结果作为数值基准。

## 2. 明确不采用的路线

不使用 MATLAB Compiler 继续发布，因为目标电脑仍需 MATLAB Runtime。

不使用 MATLAB Coder 生成整个应用。MATLAB Coder 适合生成受支持的数值
算法代码，不能把当前 `uifigure`、文件对话框、表格、绘图和导出界面完整
转换为原生 Windows UI。本项目的数值公式相对集中，直接移植并以回归测试
验证，比维护 MATLAB 生成的 C/C++ 接口更简单。

不在第一版引入跨平台 UI。目标系统固定为 Windows 10/11 x64。

## 3. 技术栈和发布形式

- 语言：C#。
- 运行平台：.NET 10 LTS。
- UI：WPF。
- 架构风格：界面、计算和文件读写相互分离。
- 发布目标：`win-x64` 自包含发布。
- 交付物：一个小于 200 MB 的便携 ZIP。

ZIP 内可以包含 EXE、必要的原生库和少量资源文件。设计不强求所有内容物理
合并为单一 EXE；运行稳定性、启动速度和总体压缩体积优先。

程序不联网、不收集使用数据。意外崩溃日志只保存在本机。

## 4. 解决方案结构

### 4.1 IPCE.Desktop

WPF 桌面程序，负责：

- 中文界面和操作流程。
- 文件选择、参数编辑和状态提示。
- 锚点表格编辑、文件导入及曲线选点。
- 交互式绘图、结果表和导出选择。
- 调用计算层和文件层，但不直接实现物理公式。

界面保留现有“左侧操作、右侧结果”的使用习惯。左侧按以下步骤分组：

1. 硅标定和单色光功率密度。
2. 样品 IPCE。
3. 光谱积分和导出。

右侧使用页签显示硅 i-t、样品 i-t、锚点、功率密度、IPCE、累计积分曲线
和结果表。所有曲线支持缩放、平移、复位、精确坐标范围及线性/对数刻度。

### 4.2 IPCE.Core

纯 C# 计算库，不依赖 WPF 或文件对话框，负责：

- 构建固定 Delay 或锚点驱动的扫描调度。
- 从可变驻留窗口提取稳定电流、样本数和标准误差。
- 独立处理硅和样品暗电流区间。
- 计算硅响应度、入射功率密度和误差。
- 把功率密度插值到样品波长并计算 IPCE。
- 选择计算 IPCE 或外部 IPCE 作为积分源。
- 线性插值、形状保持 PCHIP、梯形积分和累计积分。

这些算法直接实现，不引入大型科学计算框架。公共接口使用明确的数据模型
和数值数组，不向计算层传递 WPF 控件或电子表格对象。

### 4.3 IPCE.IO

负责：

- 读取 TXT、CSV、XLS 和 XLSX。
- 导入校准表、i-t、时间锚点、外部 IPCE 和太阳光谱。
- 识别 i-t 表头单位并转换到内部 `s/A`。
- 保留原始表头、源单位和转换因子。
- 导出 XLSX、CSV 和 MATLAB 可读取的 MAT 文件。
- 写入后检查文件存在且非空。

只选择能免费再分发、许可证兼容且经过维护的轻量库。第三方版本在项目中
锁定。XLS/XLSX 读写和交互绘图各最多使用一个主要第三方库。

MAT 导出继续提供名为 `exportData` 的顶层结构。其字段名对应用户选择的导出
表；列名和数值数据应能被 MATLAB 回读。兼容性以 MATLAB 自动回读测试为准。

### 4.4 IPCE.Tests

自动测试项目负责：

- 逐项迁移 `run_ipce_selftest` 中的回归和数值测试。
- 读取 MATLAB 生成的基准数据并与 C# 结果比较。
- 测试导入错误、状态回滚、独立后处理和各导出格式。
- 构造并关闭真实 WPF 主窗口，执行 UI 冒烟测试。

## 5. 状态和数据流

主要测量路径：

```text
校准表 + 硅 i-t + 硅锚点
        -> 功率密度

功率密度 + 样品 i-t + 样品锚点
        -> 样品 IPCE
```

光谱积分路径：

```text
计算 IPCE 或外部 IPCE + 太阳光谱
        -> 积分电流密度 + 累计曲线
```

外部 IPCE 后处理是独立路径。它不得要求校准表、硅 i-t、样品 i-t 或任何
锚点。计算 IPCE 和外部 IPCE 使用独立状态对象，导入外部数据不得覆盖已经
计算的结果。

所有文件先解析到临时对象并完成验证，成功后再一次性替换当前有效状态。
导入或计算失败时保留上一次有效结果，避免界面出现半更新状态。

## 6. 文件与单位规则

- i-t 内部列固定为 `Time_s` 和 `Current_A`。
- 支持时间单位 `s`、`sec`、`second`、`ms`、`min`、`h`。
- 支持电流单位 `A`、`mA`、`uA`、`µA`、`μA`、`nA`、`pA`。
- 无法识别 i-t 单位时，必须要求用户明确选择；不得按数值大小猜测。
- 时间锚点固定为第一列波长 `nm`、第二列确认时间 `s`。
- 外部 IPCE 使用前两列有效数值作为波长 `nm` 和 IPCE `%`。
- 光谱辐照度固定为 `W m^-2 nm^-1`。
- 积分和累计电流密度固定为 `mA cm^-2`。

外部 IPCE 按波长排序，重复波长取平均。有限的超出 `0-100%` 的数据不裁剪。

## 7. 数值行为

移植必须保持以下行为：

- 硅响应度和功率密度使用形状保持 PCHIP 插值。
- 光谱使用线性插值，IPCE 使用 PCHIP 插值。
- 不在校准覆盖、功率密度覆盖或 IPCE/光谱公共覆盖范围外外推。
- 积分网格使用光谱波长点，并补入用户指定的上下边界。
- 积分使用梯形法，累计曲线最后一点等于报告的最终积分值。
- 保留有符号总光电流列；功率密度和 IPCE 使用绝对光电流。
- 样品 i-t 是总电流，先除以样品有效受光面积得到电流密度。
- 硅和样品的波长范围、步长、Delay、锚点及暗电流区间互相独立。
- 两个以上锚点采用分段线性时间映射，并按最近锚点对的斜率向扫描两端
  外推；单锚点使用名义 Delay。

物理常数使用现有 MATLAB 实现中的精确值。结果列名、单位和统计含义保持
一致。

## 8. 启动默认值

程序内置以下默认文件：

- `标准硅探测器校准结果_证书编号 GXgf2026-01645.xlsx`
- `标准太阳能光谱数据.xls`
- `Si-i t [300 1100] nm-grating 2-filter.txt`
- `Si-i t [300 1100] nm-grating 2-filter-time match.txt`

启动时优先使用 EXE 同目录中的同名文件；找不到时使用便携包的内置副本。

默认启用暗电流扣除。硅暗区间为 `0.1-10 s`，样品暗区间为 `50-60 s`。

## 9. 错误处理

用户可预期的数据错误使用中文提示，并包含足够的定位信息：

- 文件路径和工作表。
- 缺失或无法识别的列与单位。
- 非法参数、重复锚点或非单调调度。
- 数据不足、暗区间无样本或稳定窗口无样本。
- 超出校准、功率密度或积分公共覆盖范围。
- 文件被占用、无写入权限或导出后验证失败。

输入错误不显示技术堆栈。未处理异常写入本机日志，并向用户显示日志位置。
日志不得包含遥测上传功能。

## 10. 验证标准

### 10.1 自动测试

现有 MATLAB 自测中的每项行为都要有对应 C# 测试，包括：

- i-t 单位识别、转换、元数据保留和缺失单位错误。
- 外部 IPCE 排序、重复波长平均及超出 100% 的有限值保留。
- 固定 Delay、单锚点和多锚点调度。
- 暗电流扣除、窗口提取、误差传播和面积归一化。
- 功率密度、样品 IPCE、不同波长网格插值和范围错误。
- 解析解积分、累计积分终点一致性和独立外部后处理。
- XLSX、CSV、MAT 的实际写入和回读。

表头、行数、单位、状态标志和文件结构要求完全一致。浮点结果的默认验收
标准为相对误差不超过 `1e-9`；接近零时同时使用明确的绝对误差标准。若
PCHIP 边界实现造成可解释差异，必须记录具体测试和容差，不能用统一放宽
容差掩盖问题。

### 10.2 UI 与发布验收

- WPF 主窗口能够自动构造、显示、处理消息并关闭。
- 使用真实硅和样品数据完成一次功率密度与 IPCE 计算。
- 在没有测量输入的情况下完成一次外部 IPCE 积分与导出。
- 在未安装 MATLAB 和 .NET 的干净 Windows 10/11 x64 环境运行完整流程。
- 便携 ZIP 小于 200 MB。
- 解压后无需管理员权限即可启动。

如体积超限，优先精简第三方依赖、符号文件和重复资源，不删除计算或导出
功能。

## 11. 实施阶段

1. 建立 C# 解决方案、数据模型和 MATLAB 基准数据。
2. 以测试驱动方式移植 `IPCE.Core`。
3. 实现 `IPCE.IO` 并完成各格式回读测试。
4. 实现 WPF UI、交互绘图和锚点操作。
5. 完成端到端对照、便携发布和干净系统验收。

现有 MATLAB 程序在迁移验收前保持不变，继续作为行为和数值基准。第一版
C# 程序必须完整覆盖现有功能，不以删除功能换取体积。

## 12. 完成定义

以下条件同时满足时，迁移才视为完成：

- 全部迁移测试通过。
- MATLAB 与 C# 基准对照满足规定容差。
- 完整测量与独立后处理工作流均通过人工验收。
- XLSX、CSV 和 MAT 导出可被目标软件正常读取。
- 干净 Windows 电脑可以直接运行便携包。
- 最终 ZIP 小于 200 MB。
