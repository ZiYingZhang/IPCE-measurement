# IPCE C# 可用性与 MATLAB 工作流等价设计

日期：2026-07-28

## 1. 背景

IPCE C# 便携版已经完成数值核心、文件层、WPF 外壳和自包含 Windows
发布，并通过 MATLAB 数值基准对照。然而第一次真实人工运行暴露出以下问题：

- ScottPlot 中文标题出现缺字方框。
- 除硅和样品 i-t 外，锚点、功率密度、IPCE、光谱和累计积分缺少足够的
  可视化。
- 小数参数难以输入。
- 时间调度或积分范围错误会导致应用退出。
- C# 界面的可视化和交互明显弱于 MATLAB。

进一步对照 MATLAB 工作流、迁移设计、C# 实现和自动测试后，还确认了单位
选择、光谱列选择、外部 IPCE 格式、锚点编辑、结果有效性、默认参数和
可复现导出等缺口。

本设计以“C# 可以完整替代 MATLAB 工作流”为验收标准，不仅修复最初报告的
四个表面问题。

## 2. 目标

- 保留已经通过数值对照的 `IPCE.Core` 算法行为。
- 保留现有 `IPCE.IO` 的事务式读取和写出原则，并补齐缺失格式和选择流程。
- 系统重构桌面交互层，不全面重写整个应用。
- 所有可预期输入和数据错误均可恢复，不导致应用退出。
- 防止参数改变后继续显示或导出被误认为最新的旧结果。
- 恢复并改进 MATLAB 中的导入、锚点、绘图和光谱积分体验。
- 保持外部 IPCE 后处理为独立路径。
- 保持 Windows x64 自包含便携 ZIP 小于 200 MB。

## 3. 非目标

- 不改变物理公式、插值、积分方法或数值容差。
- 不增加网络、遥测、云同步或用户账户。
- 不在本轮实现跨平台 UI。
- 不要求逐像素复制 MATLAB，但功能和实验判断信息不得退化。
- 不实现多项目数据库或复杂实验管理系统。

## 4. 总体方案

采用“保留核心、模块化补全桌面层”的路线。

桌面层拆分为以下职责：

1. `OperationRunner`：统一运行同步和异步用户操作，区分预期错误和未知异常。
2. 数字输入与验证组件：负责文化无关的有限数值解析、范围校验和错误显示。
3. 导入协调器：负责单位、工作表和列选择，再调用 `IPCE.IO`。
4. 工作流状态：记录数据是否存在、结果是否有效以及失效原因。
5. 绘图呈现组件：只把当前状态转换成 ScottPlot 图层，不实现物理计算。
6. 导出构建器：组合结果、参数、锚点和来源元数据。

计算和导入继续采用“先在临时对象中完整验证，成功后一次性替换状态”的
事务原则。

## 5. 操作执行与错误恢复

用户操作统一遵循：

```text
检查输入 -> 执行导入或计算 -> 成功后更新状态
                    |
                    +-> 预期错误：中文提示，保留窗口和旧有效状态
                    +-> 未知错误：写本地日志，提示日志位置并尽量继续
```

以下均视为可预期错误，不得触发应用终止或崩溃日志：

- 文件、工作表或列不存在。
- 无法识别单位。
- 参数不合法。
- 锚点重复或生成非单调调度。
- 暗区间、平均窗口或时间调度超出数据覆盖。
- 校准、功率密度、IPCE 或光谱覆盖不足。
- 积分范围超出公共覆盖。
- 导出目标被占用、无权限或写后验证失败。

全局 WPF 异常处理只作为最后防线。它必须明确标记已处理，避免应用在记录
日志后继续终止。同步命令和异步命令都应在操作边界捕获预期异常，不能依赖
全局处理器承担普通业务错误。

异步导入期间只禁用自身操作并显示忙碌状态，其他独立流程保持可用。例如
导入样品数据时，外部 IPCE 后处理仍可操作。

## 6. 结果有效性与依赖失效

结果状态至少包含：

- `Missing`：尚未生成。
- `Current`：与当前输入和参数一致。
- `Stale`：曾经生成，但上游数据或参数已经改变。

依赖规则如下：

| 变化 | 立即失效的结果 |
|---|---|
| 硅校准、硅 i-t、硅锚点或任一硅计算参数 | 功率密度、计算 IPCE、使用计算 IPCE 的积分 |
| 样品 i-t、样品锚点或任一样品计算参数 | 计算 IPCE、使用计算 IPCE 的积分 |
| 外部 IPCE | 使用外部 IPCE 的积分 |
| 光谱、积分边界或 IPCE 来源 | 当前积分 |

外部 IPCE 不受硅或样品测量参数变化影响。计算 IPCE 和外部 IPCE 始终保存在
独立状态中。

失效结果可以灰色显示供视觉对照，但必须显示“参数已改变，请重新计算”；
失效结果不得作为下游计算输入，也不得导出。界面必须同时显示具体失效原因，
而不是只有一个通用状态。

## 7. 数字输入

所有科学参数使用统一的有限数值输入行为：

- 接受 `0.36`、`.36` 和当前系统文化中的逗号小数。
- 输入期间允许 `-`、`.`、`0.` 等尚未完成的中间状态。
- 在失去焦点或执行操作时提交并验证，不在每次按键时强制写入 `double`。
- 不接受 `NaN`、正负无穷或含糊的千位分隔形式。
- 格式错误和范围错误显示在输入框附近，并说明允许范围。

最低约束包括：

- 面积和波长步长必须大于零。
- 波长必须为有限正值，终点不得小于起点。
- 暗区间和积分区间终点必须大于起点。
- Delay 必须大于零，平均时长不得为负。

恢复 MATLAB 的样品固定模式默认起点 `50 s`。默认值修改必须有回归测试。

## 8. 文件导入

### 8.1 i-t

自动识别表头单位并转换为内部 `s/A`。若时间或电流单位无法识别：

1. 显示原始时间和电流表头。
2. 分别要求用户选择时间单位和电流单位。
3. 使用显式 `UnitOverrides` 重新读取。
4. 用户取消时，本次导入取消且旧数据不变。

导入成功后显示文件名、点数、时间范围、原始单位和“已换算为 s/A”。

### 8.2 太阳光谱

选择文件后：

1. 列出实际工作表。
2. 读取所选工作表的真实表头。
3. 选择波长列和光谱辐照度列。
4. 拒绝选择同一列或没有足够数值的列。

默认 ASTM 文件仍自动选择 `Spectra` 工作表、A 列波长和 C 列 Global tilt，
不增加正常启动步骤。

### 8.3 外部 IPCE

支持 `.txt`、`.csv`、`.xls` 和 `.xlsx`。前两列有效数值固定解释为波长
`nm` 和 IPCE `%`。继续保持按波长排序、重复波长取平均以及不裁剪有限
超 `100%` 数据。

成功导入后自动选择外部 IPCE 为积分来源，但不删除计算 IPCE。

## 9. 主窗口与结果布局

采用用户确认的“流程状态栏 + 图表页签”方案。

左侧保持三步工作流：

1. 硅标定与功率密度。
2. 样品 IPCE。
3. 光谱积分与导出。

每一步显示：

- 输入是否齐全。
- 当前结果状态。
- 缺少的前置数据或失效原因。
- 数据覆盖与预计调度覆盖。

右侧采用以下页签：

1. `i-t 轨迹`
2. `时间调度`
3. `功率密度`
4. `IPCE`
5. `光谱积分`
6. `结果摘要`

每个数据页签以图为主，并提供可折叠数据表。表格使用明确的中文列名和单位，
不直接暴露冗长的 C# 属性名。

## 10. 绘图行为

所有 ScottPlot 图使用能够显示中文的已安装字体，优先使用
`Microsoft YaHei UI`，并在不可用时使用按文本选择最佳字体的回退。

统一交互：

- 滚轮缩放。
- 左键拖动平移。
- 双击复位。
- 悬停坐标读数。
- 可折叠的精确坐标范围和线性/对数轴设置。
- 保存当前图像。
- 图层显示开关。

大数据绘图允许为显示性能抽样，但计算、锚点吸附和导出始终使用原始数据。

### 10.1 i-t 轨迹

分别显示硅和样品：

- 原始 i-t。
- 暗电流区间。
- 首个对齐参考时间。
- 锚点或确认时间。
- 实际平均窗口。
- 窗口均值。

### 10.2 时间调度

同时显示：

- 硅调度线和硅锚点。
- 样品调度线和样品锚点。
- 对应 i-t 数据的时间覆盖边界。
- 超出覆盖范围的调度部分，以红色显示。

### 10.3 功率密度

显示入射功率密度随波长变化，并显示或可切换标准误差。图下保留完整结果表。

### 10.4 IPCE

计算 IPCE 与外部 IPCE 同图显示，允许分别隐藏，并清楚标记当前积分来源。
有限超 `100%` 外部 IPCE 按原值绘制。

### 10.5 光谱积分

上图使用双轴显示：

- 左轴：光谱辐照度。
- 右轴：当前选择的 IPCE。
- 实际积分范围以半透明区域标记。

下图显示累计积分电流密度，最终点突出显示。结果卡片显示最终
`mA cm^-2`、实际积分边界和积分功率。

## 11. 锚点编辑

硅和样品锚点分别管理。表格允许新增、编辑和删除，编辑提交后统一验证正波长、
有限时间、重复波长和调度单调性。

图上操作使用明确的“新增锚点”模式：

1. 点击原始曲线。
2. 吸附到最近原始采样时间。
3. 弹窗显示并允许修改波长和确认时间。
4. 若波长已存在，明确提示将更新该行。
5. 确认后刷新锚点表、i-t 图和时间调度预览。

批量编辑或导入失败时保留原来的有效锚点集合。

## 12. 覆盖范围与操作提示

界面在执行前计算并显示：

- i-t 实际时间范围。
- 预计调度时间范围。
- 校准波长覆盖。
- 功率密度波长覆盖。
- 当前 IPCE 波长覆盖。
- 光谱波长覆盖。
- IPCE 与光谱的公共可积分范围。

示例：

```text
样品轨迹：0–1280 s
预计调度：50–1338 s
无法计算：调度终点超出轨迹 58 s
```

按钮禁用时必须显示具体原因，不能仅让按钮变灰。

## 13. 可复现导出

保留现有结果表名称：

- `SiPowerDensity`
- `SampleIPCE`
- `ExternalIPCE`
- `SpectrumSummary`
- `SpectrumCurve`

增加：

- `MeasurementSettings`
- `SiliconAnchors`
- `SampleAnchors`
- `InputMetadata`

这些表记录：

- 硅和样品波长范围、步长、Delay、平均时长、面积、暗区间和对齐方式。
- 两套锚点。
- 输入文件名和原始表头。
- 原始单位和换算因子。
- 光谱工作表及所选列。
- 积分范围和 IPCE 来源。
- 导出时各结果的有效状态。

仅允许导出 `Current` 结果。CSV 多表命名、XLSX 工作表和 MAT 顶层
`exportData` 结构继续保持现有兼容约定。

## 14. 测试策略

所有新行为和错误修复先增加失败测试。

### 14.1 自动测试

- 小数点、逗号小数、未完成输入和非法非有限数值。
- 每一条结果依赖失效规则。
- 失效结果不能继续参与计算或导出。
- 同步和异步预期错误后应用仍然可用。
- 无单位 i-t 的选择、重试和取消。
- 光谱工作表与列发现、选择和读取。
- 四种外部 IPCE 格式。
- 锚点新增、编辑、删除、吸附、排序和硅/样品隔离。
- 每种结果状态触发正确的绘图刷新。
- 中文绘图字体策略。
- 可复现导出表及元数据。
- 完整测量和独立外部后处理。

### 14.2 真实 UI 验收

1. 默认数据计算硅功率密度。
2. 导入样品数据并计算 IPCE。
3. 修改面积，确认旧结果失效且不能导出。
4. 触发时间或积分范围错误，确认应用不退出且可继续操作。
5. 导入无单位 i-t 并完成单位选择。
6. 导入外部 IPCE 和非默认结构的光谱工作簿。
7. 检查全部图表、图层、缩放、平移、坐标读取和复位。
8. 完成积分并检查双轴光谱、累计曲线和最终值。
9. 导出并回读 XLSX、CSV 和 MAT。

### 14.3 回归与发布

- 运行全部 C# 测试。
- 运行 MATLAB `run_ipce_selftest`。
- 构造并关闭 MATLAB 原版 UI。
- 运行 C# 编译后 UI 冒烟测试。
- 重新生成并验证 Windows x64 自包含 ZIP。
- ZIP 必须小于 200 MB，不包含 MATLAB Runtime。
- 最终仍需在没有 MATLAB 和 .NET Runtime 的干净 Windows 10/11 x64
  机器或 VM 上完成人工验收。

## 15. 完成标准

以下条件全部满足才视为 C# 版本可完整替代 MATLAB：

- 两条工作流均能通过真实界面完成。
- 所有可预期错误均不导致应用退出。
- 参数变化不会产生可误用或可导出的旧结果。
- 单位、光谱列、外部 IPCE 和锚点工作流功能等价。
- 所有规定图表和交互可用，中文无缺字。
- 导出包含复现实验所需的数据、参数和来源元数据。
- C# 与 MATLAB 数值回归继续满足既有容差。
- 便携包自动验证通过且小于 200 MB。
- 干净 Windows 环境人工验收通过。
